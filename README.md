# ANKA Development Gantt Chart

Proje yönetimi ve Gantt şeması uygulaması.

## Deployment

Bu uygulama statik bir HTML dosyasıdır ve herhangi bir web hosting servisinde çalışır.

### GitHub Pages ile Deploy

1. Bu projeyi GitHub'a yükleyin
2. Repository Settings > Pages bölümüne gidin
3. Source olarak "main" branch'ini seçin
4. Save'e tıklayın
5. Birkaç dakika sonra siteniz `https://kullaniciadi.github.io/repo-adi` adresinde yayında olacak

### Netlify ile Deploy

1. [Netlify](https://www.netlify.com/) sitesine gidin ve ücretsiz hesap oluşturun
2. "Add new site" > "Deploy manually" seçin
3. `index.html` dosyasını sürükleyip bırakın
4. Siteniz anında yayında olacak!

### Vercel ile Deploy

1. [Vercel](https://vercel.com/) sitesine gidin ve ücretsiz hesap oluşturun
2. "New Project" butonuna tıklayın
3. GitHub repository'nizi bağlayın veya dosyaları yükleyin
4. Deploy butonuna tıklayın
